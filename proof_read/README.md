# Proof-read pack — report translations (draft)

These PDFs contain **draft** Telugu / Tamil / Hindi report text for native-speaker review.
English (`-en`) is the reference. Map photos are grey boxes here — only the **words** need review.

## Files

| File | Contents |
|---|---|
| `field-report-en.pdf` | Bulk report, English (reference) |
| `field-report-te.pdf` | Bulk report, Telugu draft |
| `field-report-ta.pdf` | Bulk report, Tamil draft |
| `field-report-hi.pdf` | Bulk report, Hindi draft (uses Bigha — UP, the Hindi-belt unit) |
| `field-report-single-*.pdf` | Single-field report in each language |

Sample data is identical everywhere: 3 fields (Field 3 / 5 / 7), one reporter block,
state unit Cent (Bigha-UP for Hindi).

## How to send corrections

For each fix, give: **file → page → the English line → corrected line**.
Example: `field-report-te.pdf, p1, table header "పేరు" should be "పేర్లు"`.

Anything unclear or unnatural — flag it, even if you are not sure of the perfect word.
